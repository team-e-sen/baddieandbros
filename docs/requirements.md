# Inventory System Requirements

## 1. Functional Requirements

- _FR-1:_ The system shall allow users to add a new inventory item with a name, quantity, and price.
- _FR-2:_ The system shall allow users to view a list of all current inventory items.
- _FR-3:_ The system shall allow users to update the quantity of an existing item.
- _FR-4:_ The system shall allow users to delete an item from the inventory.
- _FR-5:_ The system shall store data persistently in a JSON file.

## 2. Non-Functional Requirements

- _NFR-1:_ The system must be written in Python.
- _NFR-2:_ The system must run in the command line interface (CLI).
